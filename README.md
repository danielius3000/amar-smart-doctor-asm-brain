\# ASM Brain



\## Purpose



ASM Brain is the single source of truth for all approved organizational knowledge powering Amar Smart Doctor.



It contains the company's long-term knowledge, documentation, engineering decisions, medical knowledge, product strategy, and operational documentation.



ASM Brain is designed to be consumed by both humans and AI systems through ASM Core.



\---



\## Principles



\- Single source of truth

\- Markdown-first

\- Human-readable

\- AI-readable

\- Version controlled

\- Documentation before implementation
