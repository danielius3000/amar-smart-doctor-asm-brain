# Core Principles

## Knowledge First

Structured knowledge is the primary asset.

Website pages, videos, social media content, AI systems, and future products are outputs generated from structured knowledge.

- Research

- Translation
- Automation
- Analysis

AI output must follow verification processes.

# Maintenance Rule

Before creating a new document:

1. Check whether an existing document can be improved.
2. Avoid duplicate knowledge.
3. Keep information structured.
4. Update indexes when necessary.
